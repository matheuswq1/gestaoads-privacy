Política de Privacidade — Gestão Ads

Última atualização: 23 de setembro de 2026

Este aplicativo (“Gestão Ads”) é uma ferramenta interna de gestão e análise de campanhas publicitárias (Meta Ads e Google Ads) utilizada pela equipe autorizada do negócio Doutor Melhora / empresas vinculadas. Esta política descreve como tratamos dados pessoais no contexto do app.

1. Controlador

Contato: matheus84wq@gmail.com

2. Dados tratados

  • Dados de autenticação de usuários internos (e-mail, papel de acesso).
  • Tokens de acesso às APIs de anúncios, armazenados de forma criptografada.
  • Dados de contas, campanhas e métricas publicitárias obtidos das plataformas Meta e Google.

Não coletamos dados de pacientes clínicos por meio deste aplicativo.

3. Finalidades

  • Autenticar usuários autorizados.
  • Sincronizar e exibir desempenho de campanhas.
  • Permitir ações de gestão (pausar, orçamento, duplicar) conforme permissões.
  • Registrar auditoria de ações sensíveis.

4. Bases legais (LGPD)

Tratamento fundamentado em legítimo interesse e execução de atividades da organização, limitado a usuários com vínculo autorizado.

5. Compartilhamento

Dados de anúncios são processados via APIs oficiais da Meta e do Google. Não vendemos dados pessoais a terceiros.

6. Retenção e segurança

Tokens são criptografados em repouso. Mantemos registros pelo tempo necessário à operação e auditoria. Acesso restrito por autenticação e papéis (admin/analyst/viewer).

7. Direitos do titular

Usuários autorizados podem solicitar acesso, correção ou exclusão de dados da conta pelo e-mail acima. Para exclusão de dados do aplicativo Meta, use o mesmo contato.

8. Exclusão de dados

Para solicitar exclusão dos seus dados vinculados a este app, envie e-mail para matheus84wq@gmail.com com o assunto “Exclusão de dados — Gestão Ads”. Atenderemos em até 15 dias úteis.

9. Alterações

Podemos atualizar esta política; a data no topo indica a versão vigente.
